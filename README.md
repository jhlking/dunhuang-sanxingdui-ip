## 项目简介 · About

《丝路幻镜》是一部以**敦煌莫高窟**与**三星堆**两大世界级文化遗产为核心的国潮 IP 作品，面向欧美跨境电商场景，探索「传统文化出海 × 商业变现」的双向赋能路径。

作品突破传统文博复刻思维，原创两位角色——**胖飞天「灵羽」**与**纵目折扇「瞳瞳」**，以「自卑 → 蜕变 → 绽放」的情感叙事，传递 **「东方美不止一种标准」** 的核心理念，契合全球 Z 世代多元、包容的审美趋势。

项目以故事化视觉承载国风美妆与服饰产品，为「国潮 IP 出海」提供一套可落地、可商业化的创新设计方案。

## 设计理念 · Design Philosophy

本设计遵循 **「文物溯源、创新共生」** 原则，融合两套美学体系：

- **敦煌柔美丝路美学** —— 灵羽取材唐代飞天，还原丰腴盛唐体态，以敦煌红、绿松石蓝、鎏金构建三色体系，通过朴素与华丽的双造型反差讲述成长。
- **三星堆神秘古蜀美学** —— 瞳瞳基于纵目面具结构创新重构，将文物特征转化为可变形折扇，搭配喜剧人设消解文物的距离感。

整体融入**敦煌藻井、三星堆云雷纹**等传统纹样，实现两大文明的自然交融。

## 叙事与镜头 · Narrative & Cinematography

- **片长**：3 分钟
- **规格**：16:9 · 1080P · 25fps，适配海外主流平台传播
- **结构**：三幕式叙事，完成「冲突铺垫 → 角色蜕变 → 高光绽放」的完整闭环
- **风格**：平衡喜剧笑点与温情留白，提升观众共情；通过景深切换、低角度仰拍等镜头语言贴合角色心境，强化画面叙事力与高级感
